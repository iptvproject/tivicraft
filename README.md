# tivicraft
App IPTV player cho Android TV / Google TV, có hành vi và bố cục tổng thể tương tự các IPTV player phổ biến (xem kênh trực tiếp, sidebar nhóm kênh, EPG dạng lưới, điều khiển hoàn toàn bằng remote

Pháp lý: app không tích hợp sẵn bất kỳ danh sách kênh nào. Người dùng tự nhập playlist hợp pháp của họ.
